========================================================
MATTHEW STUDIO — PROJECT OVERVIEW & BUILD PLAN
========================================================

1. PROJECT NAME & PURPOSE
--------------------------------------------------------
Matthew Studio — a portfolio + shop site showcasing a resort
booking website template. Visitors browse past client work,
compare the 3 pricing tiers (managed SaaS / self-hosted /
custom build), learn what the template includes, read
testimonials, and book a demo. A single superAdmin account
manages the backend content (portfolio entries, pricing,
testimonials).

2. TECH STACK
--------------------------------------------------------
- Next.js 16.3.0 (App Router, Turbopack)
- React 19.2.8
- TypeScript
- Tailwind CSS v4 (+ custom design token system in
  app/styles/globals.css)
- framer-motion — section entrance animations
- lucide-react — icons
- axios — client-side HTTP calls
- Supabase — auth (superAdmin login) + database
- Fonts: Geist Sans / Geist Mono (next/font)

3. ACCOUNT TYPES
--------------------------------------------------------
- Public (no login) — all marketing/shop pages
- superAdmin — protected dashboard at /superAdmin,
  Supabase-authenticated, role checked via user_metadata.role
