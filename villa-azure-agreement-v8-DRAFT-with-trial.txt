2B. ENTERPRISE SECURITY FEATURES (AUTOMATIC, ALL TIERS)
================================================================================

RATE LIMITING (Gatekeeper 1):
• Max 5 login attempts per IP per 15 minutes (prevents brute force)
• Max 10 API requests per IP per 15 minutes (prevents bot attacks)
• If 10 failed logins in 5 minutes → IP blocked for 1 hour automatically
• Automatic unblock after time window expires

DEVICE FINGERPRINTING & NEW DEVICE ALERTS:
• Tracks browser, OS, device type on each login
• Creates SHA-256 device fingerprint (not personally identifiable)
• Alerts owner when login occurs from unfamiliar device
• Logs device change for security review
• Helps detect account compromises

GEO-ANOMALY DETECTION:
• Flags impossible travel (e.g., Manila → Singapore in 1 hour)
• Calculates distance between last login and current login
• Uses city-level geolocation (MaxMind GeoIP2, self-hosted)
• Automatic email alert to owner within 2 minutes
• Can trigger temporary account freeze (optional)

SQL INJECTION DETECTION:
• Scans all inputs for SQL attack patterns
• Blocks suspicious input patterns at request level
• Logs all attempted injections
• Owner receives alert for each attempt
• Database is protected regardless (Prisma ORM + prepared statements)

AUTOMATED BREACH ALERTS:
• Any security anomaly triggers immediate email to owner
• Alert includes: event type, timestamp, IP, location, device info
• Owner can review Security Logs in dashboard
• Optional integration with mobile alerting (SMS extra)

INTRUSION DETECTION SUMMARY:
✓ Real-time monitoring 24/7
✓ Email alerts within 2 minutes of suspicious activity
✓ No manual setup required (automatic on all tiers)
✓ Zero performance impact (async monitoring)
